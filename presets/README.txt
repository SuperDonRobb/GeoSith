GeoSith preset libraries

Weapon 6 saves new presets into the presets folder inside the configured game
folder (JK/presets in this workspace). These .gsp files are independent of levels.

Place curated default .gsp files in this folder. GeoSith lists them alongside the
player's presets, and future exports include these defaults automatically.

Preset files contain geometry, things, frames, COG parameter bindings, custom
model/template dependencies, and referenced custom resources. Stock resource
files are resolved from the player's Jedi Knight installation.
